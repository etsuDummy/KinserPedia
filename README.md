# KinserPedia

A collection of student-authored documents to help fellow students in SE I (CSCI 4250) and SE II (CSCI 4350) at ETSU.

Everything here was written by students who took the class before you. Some of it is general guidance, some of it is a snapshot of how a past team solved a specific problem. Check the **Last Verified** column before following deployment guides step-by-step — cloud provider UIs change often.

## How to contribute

See [CONTRIBUTING.md](CONTRIBUTING.md). Short version: title your work descriptively, add the metadata header (Target Audience / Keywords / Summary), prefer Markdown, and open a pull request.

## Maintenance notes

- If you find a broken link (especially in the YouTube presentations list), mark it `(BROKEN)` or open a PR removing it.
- If you follow a deployment guide and the steps still work, update its **Last Verified** date in this index — that's a valid contribution.
- Old semester-specific handouts (career services, etc.) should be replaced each year, not accumulated.
